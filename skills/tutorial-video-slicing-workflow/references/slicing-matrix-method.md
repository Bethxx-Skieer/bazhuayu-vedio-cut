# 切片矩阵方法论与扩展用法（子 Skill）

只用于教程高光切片选题。社媒宣发—效果前置模式以 [social-promo-effect-first.md](social-promo-effect-first.md) 为准，不套用本文件的爆款、花字或 BGM 建议。执行操作见 [slicing-workflow-steps.md](slicing-workflow-steps.md)。

## 一、切片矩阵：4 板块 × 5 类型 = 20 个候选位

不靠灵感，按矩阵系统化提取。

### 五种切片类型

| 类型 | 时长 | 来源板块 | 价值 | 爆款特征 |
|------|------|---------|------|---------|
| 效果展示切片 | 15-30s | 效果展示 | 钩子型，前3秒展示结果 | 视觉冲击强 |
| 教学精华切片 | 30-60s | 实操教程 | 收藏率高，信息密度高 | 单一核心技巧 |
| 痛点解答切片 | 30-60s | 业务背景/实操教程 | 共鸣强，转发率高 | 击中真实困境 |
| 金句观点切片 | 15-30s | 业务背景/功能设计 | 传播性强 | 认知输出/方法论 |
| 反转惊喜切片 | 15-30s | 任意 | 完播率高 | 意外发现/彩蛋 |

### 爆款判断标准（满足 2 条以上才二创）

1. **信息独立** — 脱离长教程上下文，单独看也能看懂
2. **情绪爆点** — 有"哇""原来如此"的反应
3. **痛点共鸣** — 击中目标用户真实困境
4. **视觉冲击** — 有 before/after 对比、动态演示
5. **可传播性** — 值得分享给朋友/同事

### 二次创作六步法

| 步骤 | 操作 | 要点 |
|------|------|------|
| 1. 重构开场 | 提取最炸瞬间放开头 | 竖版前3秒决定生死 |
| 2. 提速节奏 | 1.2-1.5x语速或手动剪气口 | 信息密度提升30-50% |
| 3. 补全上下文 | 花字/字幕补充背景 | 没看过长教程的人也能看懂 |
| 4. 加BGM+音效 | 科技感BGM，-24dB~-18dB | 人声 > BGM > 音效层级 |
| 5. 花字改造 | 关键词高亮(黄/红)，两层设计 | 底层描边+顶层填充 |
| 6. 补充片尾 | 引导关注+系列导流 | 1秒下一期预告钩子 |

## 二、切片选择策略

### 按板块的优先级

| 优先级 | 板块 | 切片类型 | 理由 |
|--------|------|---------|------|
| P0 | 效果展示 | 效果展示切片 | 爆款潜力最高，前3秒hook最强 |
| P1 | 实操教程 | 教学精华切片 | 收藏率高，教程价值明确 |
| P1 | 业务背景 | 痛点解答切片 | 共鸣感强，转发率高 |
| P2 | 功能设计 | 金句观点切片 | 技术深度，适合垂直受众 |
| P3 | 任意 | 反转惊喜切片 | 看素材是否有意外亮点 |

### 按平台选择

| 平台 | 推荐切片 | 格式 | 时长策略 |
|------|---------|------|---------|
| 抖音/快手 | 效果展示切片(15-30s) | 用户明确要求时再设计9:16版 | 7-15s娱乐，1-3min教育 |
| 视频号 | 高光快剪(完整版) | 16:9母版或按需派生 | 配合朋友圈转发 |
| 小红书 | 教学精华+痛点解答 | 3:4冰蓝品牌画布版 | 1-5min |
| B站 | 横版高光快剪+分P | 横版16:9 | 完整板块分P发布 |
| YouTube | 横版完整版 | 横版16:9 | 上传最高质量自动转码 |

## 三、扩展用法

### 3.1 批量处理多期教程

将多期 zip 放入同一目录循环处理，每期输出到独立子目录，依次执行 slicing-workflow-steps.md 的 Step 1–6：

```python
import glob, os
zip_files = sorted(glob.glob(r"{DOWNLOAD_DIR}/*.zip"))
for zip_path in zip_files:
    episode = os.path.splitext(os.path.basename(zip_path))[0]
    # {WORKSPACE} 与 {OUTPUT_ROOT} 按 episode 派生独立子目录后执行 Step 1-6
```

### 3.2 添加 BGM

对已切片视频直接混音：原声 `volume=1.0`，BGM `volume=0.15`（约 -16dB），`amix` 合成：

```bash
"$FFMPEG" -y -i clip.mp4 -i bgm.mp3 \
  -filter_complex "[1:a]volume=0.15,aloop=loop=-1:size=2e9[bg];[0:a][bg]amix=inputs=2:duration=first:dropout_transition=2[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 256k clip_bgm.mp4
```

倍速处理用 `setpts=startpts/{speed}` 与 `atempo={speed}`（1.2–1.5x）。

### 3.3 根据字幕生成对齐配音

使用 `scripts/subtitle_voiceover.py` 将 `.srt`/`.vtt`/`.ass`/JSON 转成对齐 WAV 并合回视频。先只读校验时间轴：

```bash
python scripts/subtitle_voiceover.py captions.srt --dry-run --report voiceover-plan.json
```

确认后再逐句合成。执行前必须完整读取 [subtitle-voiceover.md](subtitle-voiceover.md)；中文默认读取黎潋配置，正式交付保留 JSON 报告并核对实际声音、语速、超时句与加速比例。

### 3.4 与剪映/CapCut 配合

本流程产出的是基础格式切片（已切割、已转竖版），后续可在剪映完成：AI 自动字幕校对、花字模板、版权安全 BGM、封面大字、调速曲线。需要统一字幕样式时仍以 `scripts/burn_subtitles.py` 的规范输出为准，不得在剪映里另建一套临时字幕。

## 四、效率基准

| 工作环节 | 手工操作 | 本Skill自动化 |
|---------|---------|-------------|
| 解压素材 | 5分钟 | 30秒 |
| 视频探测+截图 | 10分钟 | 2分钟 |
| 板块边界定位 | 30-40分钟 | 5-10分钟（场景检测+截图确认） |
| 板块切割 | 15分钟 | 3分钟 |
| 切片提取+横竖版自动渲染 | 60分钟 | 方案稳定后约10-20分钟，视逐镜头取景数量而定 |
| **总计** | **~2小时** | **~20分钟** |
