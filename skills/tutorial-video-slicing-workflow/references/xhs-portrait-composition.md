# 小红书 3:4 产品演示动态合成

## 目录

- 目的与单一数据源
- 固定画布与产品框
- 内容感知取景
- 增强、字幕与音频
- 封面与质检

## 目的

把16:9产品录屏放入1080×1440品牌画布，同时保证产品区铺满、手机端可读，并让横版与竖版复用同一套剪辑、字幕、配音、音效和增强事件。

## 单一数据源

只维护一次：

- 干净的16:9剪辑时间线；
- 字幕与配音时间轴；
- 点击、输入、框选、阶段、结果和完成事件；
- 独立配音轨和音效轨。

先生成“无平台字幕增强内容母版”：录屏与所有绑定产品界面的增强层已经合成，但不包含横版底部字幕、竖版标题、竖版字幕或外层品牌画布。

```text
干净16:9录屏
＋内容绑定增强层
＝无字幕增强内容母版
        │
        ├──＋16:9字幕布局──▶ 16:9横版
        └──＋3:4品牌画布、标题、字幕──▶ 3:4小红书版
```

这是两次自动渲染，不是两套人工剪辑。禁止为竖版重新标注点击、重新画框或重新铺音效。

## 3:4 固定画布

- 画布：1080×1440，SAR 1:1；
- 背景：使用清晰的冰蓝渐变 `#EAF2FF → #D7E7FF → #DDEEFF`，不使用接近纯白、纯黑或模糊放大背景；
- 标题区：x=60、y=86、w=960、h=320；第一行为品牌蓝圆角色带白色粗体，字距 `0.02em`；第二行为中性深灰 `#3F3F3F` 粗体，字距 `0.04em`；两行间距38px，均居中；
- 产品证明框：x=48、y=457、w=984、h=672；
- 内部录屏视窗：x=56、y=465、w=968、h=656；
- 字幕区：x=60、y=1229、w=960、h=76；字幕单行、自适应宽度、结尾无句号；背景必须直接沿用横版字幕的中性灰黑 `rgba(26, 26, 26, 0.72)`，不得改成深藏蓝或其他品牌色；
- 默认两行标题的可见顶边约135px、底边约357px。标题到产品框、产品框到字幕均固定为100px，上下外部可见留白均约135px；不得靠目测临时移动模块；
- 绿色只用于真实完成状态，勾号必须使用矢量路径。

标题、背景、产品框和字幕视觉应与 `xhs-visual-template-system` 中注册的 `octopus-blue` 视频内页保持一致。若该 Skill 可用，读取其 `references/video-frame-rules.md` 和 `08-video-inner-frame.html`；本文件中的布局值是视频剪辑侧的执行基线。机器可读参数见 [../assets/xhs-portrait-octopus-blue-1080x1440.json](../assets/xhs-portrait-octopus-blue-1080x1440.json)，逐镜头取景格式见 [../assets/framing-cues.example.json](../assets/framing-cues.example.json)。

已确认的右侧重点取景动态样片接触表见 [../assets/xhs-portrait-fill-right-preview.png](../assets/xhs-portrait-fill-right-preview.png)。它只用于复核构图，不代表所有镜头固定使用右锚点。

2026-08-22确认的最终内页布局预览见 [../assets/xhs-portrait-layout-approved-preview.png](../assets/xhs-portrait-layout-approved-preview.png)。布局回归时必须核对双100px模块间距、双135px外部留白、灰色副标题和加深后的冰蓝背景。

## 产品框必须铺满

默认使用 `fill`，不能在产品框内留下上下或左右空白，也不能拉伸。对于1920×1080内容，先按内部视窗高度等比放大，再裁切超出的左右区域：

```text
1920×1080
  ↓ 等比缩放到高度656
约1166×656
  ↓ 按取景锚点裁切
968×656
  ↓ 放入
x=56, y=465
```

只有用户明确要求完整保留整个界面时才允许 `contain`。此时必须说明会出现留白，不得私自改用模糊背景。

## 内容感知取景

不要全片使用几何居中。为不同镜头建立 `framing-cues.json`，记录：

```json
[
  {
    "start": 71.5,
    "end": 80.5,
    "mode": "fill",
    "anchor": "right",
    "keep": ["对话区", "报告标题", "报告目录"],
    "discard": ["左侧无效灰色区域"]
  }
]
```

锚点规则：

- `left`：保留左侧任务、导航或输入内容；
- `center`：主体位于中央且两侧价值相当；
- `right`：裁掉左侧无效区域，优先保留右侧对话、报告或结果；
- `custom`：记录明确的源画面裁切起点。

相邻镜头的取景锚点可以不同，但单个连续操作中不要无意义左右跳动。切换锚点应发生在剪辑点、页面跳转或明显状态变化处。

## 增强效果如何复用

首选方式：先把框选、点击波纹和界面状态与16:9录屏合成，再对整个内容层执行同一缩放与裁切。这样目标与增强效果不会错位。

需要保留透明增强层时，必须对录屏和增强层应用完全相同的缩放、裁切起点和位移。不要分别凭经验调整。

竖版外层状态标签、标题和字幕可由同一事件时间轴重新渲染，但不得重新判断时间点。它们属于输出布局差异，不属于第二套增强时间线。

## 字幕与音频

- 横版与竖版共用同一份 SRT/JSON 文案和起止时间；
- 横版字幕按16:9规范渲染；
- 竖版字幕在产品框外重新布局，不能把已烧录横版字幕缩进产品框；
- 配音和音效轨原样复用，不因画幅改变而重新生成；
- 字幕、配音和状态标签仍以同一语义事件为锚点。

## 封面

从同一竖版内页派生封面，不另做一套设计：隐藏字幕，标题模块相对内页下移50px，产品证明模块相对内页下移92px，保持同一取景帧。

## 质检

- 产品录屏是否完全铺满内部视窗；
- 画面是否等比，无人物、文字或控件拉伸；
- 每个镜头是否保留真正重要的一侧，而不是默认居中；
- 无效灰区、空白区是否优先被裁掉；
- 报告标题、搜索关键词、主要按钮和结果数字是否仍可见；
- 框选、点击波纹是否仍与目标同帧同位；
- 竖版是否没有重复字幕或缩小后的横版字幕；
- 16:9与3:4的配音、音效和总时长是否一致。
