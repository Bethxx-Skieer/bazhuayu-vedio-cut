# 教程切片模式

## 适用目标

用于保留长教程结构、按章节切割、提取可独立观看的高光或批量派生社媒片段。通用配音、字幕、画面和多画幅规则仍由六个阶段规范负责。

## 素材分析

1. 探测完整教程的时长、画幅、帧率和音轨。
2. 先按固定间隔粗抽帧，再使用场景变化点定位标题卡、章节切换和重要操作。
3. 标记章节标题、效果展示、业务背景、功能解释、实操步骤和结尾。
4. 标题卡是候选边界，不自动等于最终切点；结合语音和操作完整性确认。
5. 切点需要帧级准确时使用精确 seek 和重编码；是否无损复制交给 FFmpeg 能力判断。

## 章节切割

每个章节记录：

- `segmentId`、名称和业务含义；
- 源入点、源出点和时长；
- 是否保留原声；
- 是否能独立观看；
- 推荐横版、竖版或仅归档；
- 对应的高光候选。

章节必须从完整动作或完整语义开始和结束，避免切掉句首、句尾和操作结果。

## 高光选择

优先选择：

- 脱离长教程仍能理解的完整信息；
- 明确的输入和结果；
- 可复用的单一技巧；
- 能证明产品价值的真实演示；
- 具有清楚问题与解决方案的片段。

不要只因画面变化大或存在口头情绪词就判定为高光。社媒二创需要重新建立脚本和证据链时，切换到社媒效果宣发模式。

## 输出

```text
01_板块切割/
02_横版切片/
03_平台适配/
04_字幕与配音/
05_质检/
06_工程/
```

同时保存 `segments.json`、高光候选表、源时间码、平台适配信息和项目清单。

## 禁止事项

- 在总控文件中内嵌项目专属时间码；
- 机械使用固定场景阈值代替视觉确认；
- 把所有章节都强制转换为竖版；
- 用平台运营建议替代对真实素材的判断；
- 为不同切片复制多套字幕和配音来源。
