# 视频章节卡与说明字幕规范

## 适用边界

仅把本文件用于画幅标准化、章节卡、说明字幕、字幕时间、相对位置、预览和质检。视频的叙事结构、素材取舍、章节内容和交付物仍以用户当次要求及素材为准。

具体数值的唯一机器可读来源是 [../assets/subtitle-style-1920x1080.json](../assets/subtitle-style-1920x1080.json)。渲染脚本必须读取该配置，或逐项与其保持一致；本文件负责说明使用规则，不得另建一套临时参数。

正式烧录必须调用 `scripts/burn_subtitles.py`。禁止在项目工作目录临时重写字幕渲染器、硬编码背景色或更换字体策略；只有用户明确批准新的字幕视觉时，才允许传入其他样式并使用 `--allow-style-override`。烧录报告必须保留样式文件路径、版本和 SHA-256，交付前由 `scripts/validate_render_lock.py` 校验。

## 单一时间源原则

所有视频先生成标准 `1920×1080`、`SAR 1:1`、`DAR 16:9` 横版母版，再添加章节卡和说明字幕。原始录屏不是严格 16:9 时，先按以下顺序标准化：

1. 社媒宣发成片默认等比放大并裁切铺满 `1920×1080`，横版母版不保留内部黑边。
2. 裁切必须按镜头做内容感知定位：默认居中；顶部包含搜索框、标题或导航时顶对齐；关键内容偏左或偏右时相应调整横向锚点。
3. 单一裁切无法同时保留关键内容时，可在不同镜头切换锚点、使用缓慢推拉或局部放大，但必须让用户看得出完整任务环境，不能只剩孤立文字。
4. 只有完整教程确实需要保留整个软件界面、且裁切会损失关键操作时，才使用纯黑补边；不得使用模糊背景填充。
5. 禁止拉伸画面凑成 16:9。
6. 字幕必须在标准化后的 16:9 内容坐标系中生成，不能绑定原始素材尺寸。

公众号横版和小红书 `3:4` 共用同一份字幕文案、起止时间、配音和音效，但使用各自的版式渲染：

- 先生成不含平台字幕的 `1920×1080` 增强内容母版。
- 横版在 16:9 坐标系中渲染统一底部字幕。
- 竖版按 [xhs-portrait-composition.md](xhs-portrait-composition.md) 放入冰蓝品牌画布，并在产品框外渲染单行字幕。
- 两版字幕文字和时间码必须一致；只允许位置、字号和容器随画布规则变化。
- 配音、音效和真实事件时间点原样复用，不因画幅改变而重新判断。

只有用户明确要求“完整保留横版画面、接受黑色留边”时，才使用旧兼容模式：把已经完成的 16:9 成片缩放为 `1080×608`，放在 `1080×1440` 纯黑画布的 `y=416`。兼容模式不得作为默认小红书方案。

## 统一渲染与缩放

以下全部像素值以 `1920×1080` 母版为唯一设计基准。输出其他 16:9 分辨率时统一使用：

```text
scale = output_width / 1920
x' = x × scale
y' = y × scale
size' = size × scale
```

- 横纵坐标、字号、框高、圆角、内边距和行距必须使用同一比例。
- 文字与背景框必须在同一坐标系中生成并作为同一图层放置。
- 强制输出偶数宽高、`setsar=1`、`yuv420p`。
- 禁止分别凭经验调整文字和背景框。

## 章节卡

章节卡只用于章节或模块切换，不用于普通操作说明。

### 固定尺寸与位置

- 外框：`x=76`、`y=404`、`w=1768`、`h=272`。
- 圆角：`26px`。
- 背景：深蓝黑 RGBA `(0.04, 0.08, 0.14, 0.90)`。
- 内容区左右内边距：`72px`。
- 主标题：苹方 `PingFang SC Semibold`，白色，`70px`，行高 `86px`。
- 副标题：苹方 `PingFang SC Medium`，浅蓝色，`37px`，行高 `52px`。
- 主副标题间距：`14px`。
- 主副标题均水平居中；整个文字组在卡片内垂直居中。
- 中文字间距固定为 `0`，不得人工插入空格制造疏密。

### 固定时间与动效

- 默认持续 `1.8秒`；只有用户明确要求时才调整。
- 前 `0.18秒` 淡入，后 `0.20秒` 淡出，不使用弹跳、缩放或逐字动画。
- 同一视频的全部章节卡必须复用同一位置、尺寸、字体、字号、颜色和动效。
- 章节卡显示期间不显示底部说明字幕，避免两层文字竞争。

## 底部说明字幕

说明字幕用于解释当前画面中的动作、节点或结果，不做机械逐字转录。

社媒视频的默认字幕必须是“短句、单行、紧凑容器”，不能做成承担整段说明的深色信息卡。以下情况直接判定为不合格：字幕自动折成两行；背景宽度接近整幅画面；一句话塞入两个以上语义动作；使用人工白色描边把普通字体撑成粗体；配置声明圆角但实际渲染成直角。

渲染前优先调用 `scripts/subtitle_layout.py`，统一删除句末句号、测量文字宽度并计算背景框。脚本返回 `fits_single_line=false` 时必须拆分字幕，禁止绕过检查直接换行。

### 单行自适应容器

- 只允许单行字幕，不再提供双行样式。
- 字幕框始终水平居中，中心点固定为 `x=960`；底边固定为 `y=958`，底部安全距离 `122px`。
- 单行框固定为 `y=876`、`h=82`；宽度根据当前字幕的实际像素宽度变化。
- 宽度计算：`字幕框宽度 = 文字实际宽度 + 2 × 42px`，然后限制在 `320–1600px`。
- 使用字体真实 bounding box 测量文字；字幕框宽度取偶数像素，`x = (1920 - 字幕框宽度) / 2`。
- 最长内容宽度为 `1516px`。超过后禁止换行或缩小字号，必须按语义拆成两条连续字幕，并重新分配时间码。
- 圆角：`16px`。
- 背景：中性灰黑 RGBA `(0.10, 0.10, 0.10, 0.72)`；必须实际渲染为圆角矩形，不得用普通 `drawbox` 冒充圆角容器。
- 左右内边距：`42px`。

### 固定文字

- 字体：优先苹方 `PingFang SC Semibold`；不可用时使用冬青黑体简体 `W6` 等原生粗体中文字体。
- 字号：`48px`，行高 `60px`，字色白色。
- 必须使用字体自身的 Semibold/W6/Bold 字重；禁止给白字添加同色描边来模拟粗体，避免笔画发胀、字腔粘连。
- 文字在自适应字幕框内水平、垂直居中。
- 使用字体真实 ascent、descent 和 leading 计算基线，不用字号估算基线。
- 默认前 `8%` 淡入、后 `10%` 淡出。

字幕遮挡关键界面时，先缩短文案；仍无法解决时，整条视频统一上移字幕组件。禁止只移动某一条、临时缩小字号或改变对齐方式。

## 文案与排版

- 一条字幕只表达一个动作、节点或结果，并且始终只有一行。
- 删除字幕末尾的中文句号 `。` 和英文句号 `.`；问号、感叹号属于语义或情绪时可以保留。
- 推荐格式：`节点名称｜当前画面的核心信息`。
- 分隔符统一使用全角 `｜`，两侧不加空格。
- 中文引号统一使用 `「」`。
- 中文字间距固定为 `0`。
- 中文与英文、数字之间保留一个半角空格，例如 `安装 Skill`、`Excel 数据包`、`HTML 可视化报告`。
- 英文缩写内部不插空格；画面显示 `HTML`，不要显示成 `H T M L`。配音发音替换另行处理。
- 禁止行首、行尾空格和连续两个空格。
- 不拆分专有名词、数字、Skill 名称或交付物名称。
- 为了让背景框保持紧凑，单条建议不超过 `20` 个中文等宽字符。先压缩文案；仍过长时按语义拆成两条连续字幕，禁止自动换行、缩小字号或拉满固定宽框。
- 操作类字幕显示 `2.5–4秒`；关键成果类字幕显示 `5–8秒`。
- 字幕必须与当前画面同步，不提前描述下一镜头，也不跨越镜头切换。

说明字幕默认是画面文案，不自动等同于配音稿。需要字幕转配音时，另按 [subtitle-voiceover.md](subtitle-voiceover.md) 判断朗读文本和发音替换，并校验每句可用时长。

## 预览优先工作流

用户要求“先看效果”或样式尚未确认时：

1. 先给出完整字幕文案和时间表。
2. 从真实、信息密集画面生成章节卡，以及短、中、长三种单行自适应字幕预览。
3. 用同一字幕时间源分别生成 16:9 横版预览和 `1080×1440` 冰蓝品牌竖版预览。
4. 竖版同时验证标题、产品框、逐镜头取景锚点和框外字幕；用户只改位置时先更新预览。
5. 两版预览确认后再渲染成片；不得分别改写字幕文案或重新标注时间。
6. 已有用户确认样式时，仍先渲染包含短、中、长字幕的前 `60秒` 预览；核对灰黑半透明圆角底、原生白色粗体、单行紧凑宽度、位置和字形完整后，才烧录整片。

## 成片质检

### 16:9 母版

- 检查输出是否严格为 16:9、`SAR 1:1`，画面无拉伸。
- 检查所有章节卡的外框、文字中心、字号、间距和显示时长一致。
- 抽查短、中、长字幕，确认背景框随文字宽度变化、水平居中、宽度不超过画面 `83.34%`，且底边固定为 `y=958`。
- 检查背景是半透明中性灰黑圆角矩形；检查文字使用原生粗体字形且没有人工白色描边。
- 检查所有说明字幕均为单行，末尾不含中文或英文句号；过长文案已拆成连续字幕。
- 检查中英文空格、全角分隔符、引号和换行规则。
- 检查章节卡与底部字幕不同时出现。
- 检查字幕与画面语义同步，切换点无重叠、空闪或截断。

### 3:4 品牌版

- 检查输出为 `1080×1440`、`SAR 1:1`、`DAR 3:4`。
- 检查冰蓝品牌画布、居中双行标题、产品框和框外字幕均符合 `xhs-portrait-composition.md`。
- 检查录屏完全铺满 `968×656` 内部视窗，没有白边、黑边、拉伸或模糊背景。
- 检查每个镜头按 `framing-cues.json` 保留任务输入、关键词、对话区、报告或成果等真正关键内容。
- 对比横版同一时间点，确认字幕文案、起止时间、配音和音效一致；仅版式不同。
- 检查内容绑定的框选和点击波纹经过相同缩放与裁切后仍与目标对齐。
- 检查输出时长、帧率、音视频同步、编码兼容性和可播放性。

交付前至少抽查片头、每个章节入口、短中长单行字幕、每类成果画面和片尾。
