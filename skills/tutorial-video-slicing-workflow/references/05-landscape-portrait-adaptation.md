# 阶段五：横版与竖版适配

## 目标

从同一内容时间线派生16:9、3:4或其他平台画幅。平台版本只负责布局和裁剪，不复制旁白、字幕、音频和镜头数据。

## 单源结构

```text
project-manifest.json
└── contentTimeline
    ├── narration
    ├── subtitleCues
    ├── shots
    └── audio
        ├── landscape layout overrides
        └── portrait layout overrides
```

平台版本必须引用相同的 `contentTimelineId`。不得在竖版组件内重新定义 `videoShots`、素材入点、播放速度或字幕 cue。

## 共用内容

- 自然句和配音；
- 字幕文字、顺序和时间；
- 镜头 ID、素材 ID、源入点和源出点；
- 播放速度与镜头边界；
- 状态标题、主标题和业务含义；
- 音效与增强事件。

## 允许覆盖的布局

- 画布尺寸和安全区；
- 产品框、标题区、品牌标识和字幕区位置；
- 字号与组件排版；
- 逐镜头裁剪锚点或自定义焦点；
- 横竖版专属背景和装饰。

## 语义化裁剪

先记录镜头语义，再由画幅适配器决定裁剪：

| 镜头语义 | 默认竖版策略 |
|---|---|
| `input-single-panel` | 居中，保持左右留白对称 |
| `result-single-panel` | 居中；结果位于边侧时使用 `result-side` |
| `report-split-panel` | 保留报告标题和核心结论，可偏向结果侧 |
| `report-index` | 完整展示，不快速闪切详情 |
| `full-interface` | 根据关键词、导航或操作区域设置焦点 |
| `component` | 重新排版，不缩放已烧录横版成片 |

裁剪不得切掉任务输入、报告标题、关键指标或结论。输入类页面在没有明确侧重点时一律居中。

## 字幕与标题

- 共用唯一字幕文案和时间线，分别渲染布局；
- 不把已经烧录字幕的横版整体缩进竖版产品框；
- 品牌标识、状态标题和主标题使用固定层级；
- 以实际可见边界检查模块间距，不只检查容器坐标；
- 字体、颜色和卡片样式从统一设计令牌读取。

## 渲染顺序

1. 渲染无字幕、无配音的内容母版或统一 Remotion 内容层；
2. 读取同一内容时间线生成横版布局；
3. 读取同一内容时间线和裁剪语义生成竖版布局；
4. 合入同一配音和字幕时间线；
5. 输出代表镜头的横竖版对照关键帧。

## 自动检查

- 所有平台版本引用同一 `contentTimelineId`；
- 平台覆盖项中不存在第二份 `shots`、`subtitleCues` 或 `narration`；
- 镜头数量、ID、入点和播放速度一致；
- 字幕 cue 数量、文字和时间一致；
- 关键内容位于安全区；
- 裁剪后无明显不对称空白或关键区域缺失。

## 通过条件

- 横竖版内容完全同步；
- 差异仅来自布局和取景；
- 代表镜头的字体、标题层级、间距和裁剪通过视觉检查。

完成所需平台渲染后把状态更新为 `variants_rendered`。
