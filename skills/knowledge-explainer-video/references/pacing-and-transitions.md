# 节奏、时间线与转场

## 声音是正式时间源

人工录音保持原速。按实际音频标记每个自然句的开始和结束；字幕、视觉节拍、场景和转场都引用这些时间。句间通常保留 0.3–0.6 秒，章节间 0.8–1.2 秒。关键结论在说完后保持 1.5–2.5 秒。

## 分层节奏

- 大场景通常 8–15 秒；开场、结尾或短转折可以更短；
- 场景内部每 3–6 秒发生一次有意义的推进；
- 推进优先采用增加新图片、局部展开、人物换姿势、关系线生长或真实素材切入；
- 不能为了满足变化频率而整屏闪切；
- 短标签至少可读 2.5 秒；长文字应拆成视觉层级或配合旁白逐步出现。

## 连续转场

默认 `continuity`：选择上一场景中已经存在的卡片、图片、人物、节点或按钮作为 `anchorId`，让它移动、缩放、展开、变形或换内容，成为下一场景的真实载体。转场通常 0.8–1.5 秒，并在句尾或章节停顿处发生。

只有明确的章节重置可以使用 `section-reset`。即使重置，也要保留背景、颜色、人物动作或方向中的至少一个连续线索。

禁止：

- 无来源的全屏色块突然盖住画面；
- 新旧场景先硬切，再补一个动画；
- 同一锚点在场景和转场层同时出现；
- 文字在同一帧直接替换；
- 箭头从一个来源无意义地分散到平行结果；
- 轴线没有延伸到最后节点或节点不对称。

文字更新必须经历：旧文字消退 → 内容替换 → 新文字出现。主要标签的完整替换至少留出约 0.8 秒。

## 边界检查

对每个转场时间点导出 `-1 frame / boundary / +1 frame`。检查：下一场景是否提前出现、上一场景角色是否残留、锚点是否重复、背景是否闪烁、文字是否重叠、箭头和连线是否断裂。
