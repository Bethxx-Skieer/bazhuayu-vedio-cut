# 节奏、时间线与转场

## 声音是正式时间源

人工录音保持自然速度，只修剪口误和明显多余的首尾空白。按实际音频标记自然句、重点词与停顿；字幕、动作、场景和转场都引用同一时间源。句间通常保留 0.3–0.6 秒，章节间 0.8–1.2 秒，关键结论揭示后保留足够理解时间。这些数值用于排查过快节奏，不用于强行改速或制造静音。

## 分层节奏

- 大场景通常 8–15 秒；开场、结尾或短转折可以更短，讲解复杂关系也可以更长；
- 场景内部约每 3–6 秒推进一个主要认识，不把指针、表情、局部高亮等微动作算成新焦点；
- 每个主要动作设计“出现 → 操作 → 反馈 → 停留 → 交接”，按内容省略不适用阶段，但不能仅闪出结论；
- 推进优先采用新图片、局部展开、人物操作、关系线生长、镜头重构或真实素材切入；
- 不能为了满足变化频率而整屏闪切；
- 短标签应有足够阅读时间；长文字拆成视觉层级，随对应旁白逐步出现。画面持续运动不等于观众已经理解。

## 连续转场

默认 `continuity`：选择上一场景中已经存在的图片、人物、节点、界面或按钮作为 `anchorId`，记录其起止位置、方向和交接时刻，让它移动、缩放、展开或变形为下一场景的真实载体。布局差异较大时，可用有方向的不透明遮罩揭示新布局，同时保留同一物件或运动线索。通常约 0.8–1.5 秒只是参考，应由旁白停顿、画面信息量和阅读负担决定。

只有明确的章节重置可以使用 `section-reset`。即使重置，也要保留背景、颜色、人物动作或方向中的至少一个连续线索。

禁止：

- 无来源的全屏色块突然盖住画面；
- 新旧场景先硬切，再补一个动画；
- 同一锚点在场景和转场层同时出现；
- 文字在同一帧直接替换；
- 箭头从一个来源无意义地分散到平行结果；
- 轴线没有延伸到最后节点或节点不对称。

文字更新必须经历：旧文字消退 → 载体变化或内容替换 → 新文字出现；不把新旧标题叠在同一帧。复杂说明需要更慢的中间状态，让观众看到转场怎样发生。

## 字幕与配乐

- 新项目默认字幕开启；第一次确认可关闭。以实际录音的自然词组和停顿拆分，问句与下一句分开，不拆词、不逐字跳动；默认底部单行，必要时至多两行。
- 使用 Remotion Caption JSON 作为时间源，并导出独立 SRT。每条字幕有 `text`、`startMs`、`endMs`、`timestampMs`、`confidence`；检查顺序、重叠、末尾越界与画面遮挡。
- 选用来源与许可清晰的配乐。先按实际旁白混音并试听，再确定音量与必要的人声避让；不把某一首配乐的增益数值当通用标准。

## 边界检查

对每个转场时间点导出 `-1 frame / boundary / +1 frame`；对复杂动作另查起点、中间状态和落点。检查：下一场景是否提前出现、上一场景角色是否残留、锚点是否重复、人物或卡片是否穿模、背景是否闪烁、文字是否重叠、箭头和连线是否断裂，字幕是否挡住关键交互。
