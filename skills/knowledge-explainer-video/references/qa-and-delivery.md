# 质检与交付

## 正式渲染前

固定检查：

1. 开场、核心解释和结尾代表帧；
2. 第二次确认使用的 8–12 秒转场样片；
3. 全片低清预览；
4. 每个场景边界的前一帧、切换帧和后一帧；
5. 最长文字、最复杂关系图、人物最大和最小尺寸；
6. 所有真实视频的裁剪、许可和内容对应关系。

## 自动检查

- `validate_project.py` 无 error；
- 内容和视觉两次确认均为 approved；
- 正式成片存在人工录音音轨；
- 视频为清单指定画幅和帧率；
- 最终时长与清单及人工录音一致；
- FFmpeg 完整解码无错误；
- 视觉覆盖、纯文字占比、转场时长和场景连接满足清单；
- 所有选定资产存在，网络真实素材有许可与来源。

使用：

```bash
python scripts/qa_render.py project-manifest.json final.mp4 work/qa
```

脚本生成媒体报告，并为每个场景边界提取三帧。自动报告不能代替人工视觉判断。

## 人工检查

- 讲解是否从问题与价值出发；
- 每个观点是否有易懂画面；
- 图片丰富但是否仍能慢慢看清；
- 人物外观、姿势和表情是否连续；
- 转场是否由上一画面自然演变；
- 是否存在提前出现、残留、闪屏、文字硬替换或箭头歧义；
- 真实视频是否真正证明或说明当前内容；
- 字幕是否与人工录音一致且无遮挡。

## 交付

交付最终视频、讲稿、字幕、来源与许可表、分镜、选定图片、角色设定、质检报告和可复现 Remotion 工程。候选图、下载缓存、静音预览、失败渲染和旧版本保留在 `work/`，不进入正式交付，也不提交 Git。
