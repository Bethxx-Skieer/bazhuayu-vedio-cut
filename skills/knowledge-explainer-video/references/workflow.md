# 端到端工作流

## 输入与默认值

最低输入只有主题和资料。缺省时采用：知识型普通观众、横版 1920×1080、30fps、自适应时长、人工录音、默认字幕，以及素雅简洁漫画感候选风格。90–180 秒仅是初步估计，不限制必要的讲解长度。不要静默锁定审美；第一次确认时把推断和选项一起交付。

## 阶段产物

| 状态 | 必备产物 | 进入条件 |
|---|---|---|
| `initialized` | `project-manifest.json` | 已记录主题和资料位置 |
| `evidence_ready` | 来源与观点证据表 | 事实可追溯，未知项已标记 |
| `content_approved` | 唯一讲稿、章节与第一次确认记录 | 用户确认内容、风格方向、人物和真实视频策略 |
| `visual_direction_approved` | 启用时的角色设定、三张代表帧、转场样片 | 用户完成第二次确认 |
| `assets_ready` | 选定素材与来源清单 | 所有视觉节拍有可用资产或组件 |
| `voice_locked` | 唯一人工旁白音轨与真实时长 | 录音完整性已核验，授权处理已记录，下游统一按此音轨对齐 |
| `timeline_locked` | 实际句子、字幕、场景动作、视觉节拍、转场与配乐方案 | 总时长与录音一致 |
| `preview_approved` | 低清预览、边界帧与修改记录 | 内容与视觉预览通过 |
| `rendered` | 正式 MP4 | 使用锁定清单完成渲染 |
| `qa_passed` | 自动报告与人工检查表 | 无阻塞错误 |
| `delivered` | 最终视频、讲稿、素材表、工程 | 交付内容互相对应 |

## 第一次确认包

- 一句话目标和目标受众；
- 选用的叙事模型及章节作用；
- 完整讲稿、每句目标时长和预计总时长；
- 每句证据或视觉方向；
- 每句对应的知识点、人物或物件动作、可见结果和素材需求；
- 2–3 个视觉风格方向，明确推荐项；
- 卡通人物开关、角色作用和预计姿势；
- 真实视频开关、预计占比、已有素材与需检索部分；
- 字幕开关（新项目默认开启）、字幕安全区和配乐方向；
- 横版母版和可选派生版本。

用户修改时只更新同一份清单并增加版本号。

## 第二次确认包

- 锁定的色板、字体、描边、阴影、图片质感和动效强度；
- 启用人物时的角色设定图与 6–10 个透明贴图计划；不用人物时列出承担操作的关键物件；
- 开场、核心解释、结尾三张代表帧；
- 真实视频候选及许可说明；
- 8–12 秒样片，至少包含一次组件连续转场；
- 预估的图片、真实视频、组件和纯文字占比。
- 人物与知识组件的交互方式、字幕在代表帧中的安全位置。

## 人工录音分支

内容确认后立即交付按自然句分段、适合直接朗读的录音稿。用户可提供一条总轨或逐句音频。先按 [audio-and-export.md](audio-and-export.md) 核验完整性，保留自然速度或执行用户明确授权的处理，再根据最终音轨锁定重点词、动作、字幕与画面。录音缺失或源文件缺损时可以继续生成视觉资产和静音预览，但不得进入 `voice_locked` 或正式交付。

## 增量修改

事实或讲稿变化会影响其下游；重新检查受影响的动作、字幕与时间戳。单张图、人物姿势、裁剪或转场变化只重做对应资产、场景和预览，再复查相邻交接。不要因为一个局部修改重新生成所有图片，也不能只检查修复帧而跳过全片终审。
