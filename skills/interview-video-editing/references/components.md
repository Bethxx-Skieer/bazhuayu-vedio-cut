## 3. 默认组件库：具体怎么剪

### C01 金句快切

**输入：**候选原声、对应金句、必要引导语、镜头裁剪与文字锚点。

- 先选能独立听懂、有冲突/判断/结果的短句，组合起来能指向全片主线，不固定必须八句。
- 删除句间等待，声画同步切；不裁掉发音、不改变意思，不盲目统一加速。
- 默认人物实拍＋随文字宽度适配的纯黑不透明底块；一屏通常两行主文字，一个重点。
- 小引导语统一50px，不再做看不清的装饰小字。
- 逐镜头选择脖子以下至胸口附近的文字位置，不挡脸、不落入底部操作区。
- 黑底先于主字约0.06秒，主字0.14—0.24秒短促进入；保留快切感，不做金句在外围堆积汇聚。
- 可选高潮变体：纯黑满屏超大金句；同一开场不滥用高潮。
- 不额外叠一套重复全文字幕，避免双重阅读负担。若使用提炼金句，明确它不是逐字字幕。

**输出：**高密度原声钩子段；主旨页紧接，不留无意义空场。

### C02 人物＋主题＋章节入口页

**输入：**真实人物形象、姓名身份、两行主题、默认三个章节关键词组。

- 纯黑背景，上方两行主题整体居中，右下人物，左侧三个气泡错落排列。
- 抠图保留真实五官比例；白色描边沿全部可见外轮廓，黑衣服和手臂遮挡单独校正，不使用悬空折线框。
- 人物卡位于人物图层之上，沿用四角星＋姓名＋短横线＋身份的渐变胶囊，文字深灰。
- 人物卡不再附一行卡外身份说明；标题不加顶部短横线。
- 人物和卡同步同方向入场1.5秒；随后标题逐字出现共1.5秒；三个气泡依次各1秒。
- 最后一个气泡完成，立即开始首个问题气泡放大，不增加主题页静止等待。
- 三个气泡是章节入口，不一定与问题数量一一对应：多个场景可以归为一组，如“巡店/补货/申诉/建联”。

**长标题处理：**先压缩主题表达或调整语义分行，不默认缩成小字、挤压人物。

### C03 Q问题卡与气泡放大

**输入：**章节编号、语境行、完整问题、关联主题气泡。

- 首个Q从对应的小气泡原位置放大，1秒完成；纯黑背景逐步接替人物页。
- 使用本次最终的渐变细边气泡、断开的顶部标签与右上空心问号，不引入参考图的暖黄或卡通风。
- 框内语境和问题共三行，依次出现；问题可以分行但不能删成不完整意思。
- 默认出字每行0.4秒、启动间隔0.45秒，完整画面默认再保留0.3秒。
- 当前默认“放大＋出字＋短停留”合计2.6秒；问题较长时延长阅读时间，不硬压进固定秒数。
- 后续Q复用同一Q卡；无需每章重播人物主题页，从上一回答接入同款Q框即可。
- 一个大模块只出现一次Q卡，内部推进小节不反复提问。
- Q不配虚构旁白，默认不新增打字或飞入音效。

### C04 正式访谈回答

**输入：**该问题的原声小节、逐句字幕、每小节两行核心观点、对应证据。

**默认画面：**顶部两行核心观点＋中部人物访谈画面＋底部同步字幕。

- 回答默认原速；去冗余、留逻辑，不按片头金句速度连砸整段正文。
- 顶部观点是编辑提炼，第一行白色、第二行品牌渐变；按内容小节更新，不随每句字幕跳动。
- 底部字幕忠实复现正在说的原话，按完整语义分屏；发现转写错误必须回听确认。
- Q卡完整退入回答后，同一问题的多个小节连续播放，靠原声、观点与证据推进。
- 人物保留头顶安全区，不让头发贴边；机位变化按人脸位置重新取景。
- 遇到跳切可用真实第二机位或相关证据画面覆盖，不能为遮切口插无关画面。
- 原声需要承上启下的指代或条件不能任意删除；拼接后必须仍能独立理解。
- 不在顶部观点之外再堆多张编辑总结卡，数字或流程仅在确有解释价值时出现。
- 只有问题真正转换时，才进入下一张Q卡。

### C05 业务证据与解释插入

**输入：**原声时间段、证据ID、真实录屏/报告/截图，或明确标记的解释动画。

- 真实材料优先，出现时机与所讲事实一致；能证明什么就展示什么。
- 讲过程时给关键动作，讲结果时给稳定结果；删加载和无变化等待。
- 重要数据、异常、结果应可读，不能高速闪过一堆界面。
- 插入证据时人物原声可持续，不为切画面打断回答；保留底部字幕。
- 证据显示完返回人物，延续同一问题，而不是重新起一段。
- 无真实素材时复用轻量单线流程、关系或时间线组件；明确是说明，不伪造系统结果。
- 敏感信息展示前确认或脱敏；不能为画面完整暴露无关个人或业务数据。

### C06 数字/关键结果强调

- 只强调原声中出现且有来源的数字与结果。
- 同屏只突出当前理解所需的信息，不将每个名词都做成花字。
- “断货—少赚钱／滞销—就亏钱”是本次风险对照组件样本，可以替换标签和值。
- 组件颜色、字体、字距跟随统一配置；不新增一套强调色。

### C07 价值收束与尾卡

- 先用受访者的原声完成价值落点，再回到片头命题，形成首尾呼应。
- 不在结尾堆新事实、新功能或未经授权的宣传口号。
- 复用主题页的字体、配色和核心表达，不另起一套尾卡风格。
- 无旁白；音乐自然收束，停留时长以文案可读为准。

| 辅助字与字幕 | 字距0.02em，行高1.38 |
| 金句字号档位 | 默认106px；长句96px；单行冲击120px；高潮132px |
| 金句小字／风险标签 | 50px，字重720 |

| 章节气泡 | 48px；双行场景词39px |

正文与片头字号不同是角色分工，不是两套风格；配色与字体为同一来源。换品牌时整套替换渐变参数，不逐组件手改。换字体或画幅时需重新测量排版。

### 默认布局与部件形态

- 主题标题块：x54、y163、宽972，两行居中。
- 人物：右下锚定，当前样本容器871×1098；换人物时根据真实抠图调整留白和尺度，不拉伸人体以凑坐标。
- 三个气泡：起点依次(126,535)、(246,723)、(126,911)，左—右—左错落，块间距80px；单行框约384/390×108，双行框350×166。
- 气泡：黑底、3px品牌渐变细边、小圆角、短尾部，不倾斜、不加卡通厚阴影。
- 人物卡：(160,1264)，478×94，左上/右下48px圆角，其余直角，渐变底、深灰字、实心四角星。
- 人物描边：纯白，样本素材坐标4px，跟随显示比例；新人物需由其真实轮廓重新生成，不复用齐钧泽轮廓路径。
- Q框：(70,480)，宽940，主体高430，含尾部容器高500；文字与标签保持既定安全距离。
- 正文样片：顶部观点起点约y142、左右60；视频约y360、高760、横向铺满；底部字幕约y1192、宽920、最小高104。
- 正文视频上下边框同一渐变、约3px；联合品牌位按项目是否需要启用，不恢复片头装饰英文。

### 可替换项与不重做项

| 下次替换 | 默认直接复用 |
| --- | --- |
| 视频、音频、转写、时间码与证据 | 素材索引与执行脚本表结构 |
| 主线、主题、金句、Q&A与章节关键词 | 成片骨架与各模块职责 |
| 人物照片、姓名、身份、真实轮廓 | 人物卡形态、排版与图层关系 |
| 品牌渐变、可选Logo | 一套参数驱动全片的方式 |
| 每镜头取景与字幕锚点 | 不挡脸、头顶留白、底部安全区规则 |
| 因文案长度需要的阅读时间 | 默认动效顺序、逐字/逐行进入机制 |

只有用户明确要新风格、换画幅，或现有组件确实承载不了新内容时，才扩展模板；不能每个项目都重新进入自由设计。
