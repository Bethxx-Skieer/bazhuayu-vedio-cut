# 人物访谈视频字幕与音频调整流程

适用于以受访者真实原声为主的人物访谈成片。目标是可读的自然断句、逐句声字同步、干净但不失真的受访者声音，以及连续的画面。原始素材只读；所有修复在工作副本中完成。先做一条样段确认字幕样式、声音强度和剪辑尺度，再按同一标准批量处理。

## 1. 建立源与时间映射

1. 记录原视频、机位、音轨、帧率、时长和已有字幕/脚本；核对受访者姓名、术语、数字和事实。不要把脚本当作逐字原声。
2. 为每个采用片段保留源文件、源入出点和成片入出点。所有删除、拼接或变速都更新同一份源到成片时间映射。
3. 抽取原声用于识别和回听，但始终以对应画面的原声复核，不凭自动转写或静态截图判断说话时间。

## 2. 逐句识别与文本修订

1. 先自动转写作草稿，再逐句回听受访者原声，校正专有名词、数字、否定词、语气和说话人归属。听不清的词回听上下文，不猜造事实。
2. 删除无信息量的口头重复、明显口误与自我修正；有冲突时保留说话者最后表达且符合上下文的意思，不把未说出的新结论写成字幕。
3. 采访者的提问若承担叙事作用，按脚本保留；单纯表示认同的“嗯、是的”等默认不做字幕。若其声音独立、且删除不影响受访者语义与自然节奏，可连同对应音画区间剪除；与受访者重叠时不得靠生硬静音破坏受访者发音。
4. 观点标题、Q 卡和正文字幕分开维护。标题可概括，正文字幕贴近实际原话，不拿概括文案代替同期声。

## 3. 自然断句与上屏

1. 以语义完整、自然停顿和画面阅读节奏共同划分 cue。关联紧密的短词并入相邻句，不把“和 KOC”“对吧”等单独留一帧，也不在句中机械按固定字数切开。
2. 单条字幕尽量一行，严格受画幅安全区与既定字号限制；过长则在语义边界拆成连续 cue，不缩小字号、不自动折成意外的两行。确需两行时由项目样式明确许可。
3. 标点、数字、英文缩写保持统一；口语可轻度书面化，但不得改变主语、时间、数量和因果。合并“对吧”等语气词时放到所属上一句，且显示时间覆盖对应发音。
4. 每条 cue 保留独立 ID、文字、源起止与成片起止，修改只在唯一时间线上进行。

## 4. 精确对齐

1. 用转写时间戳和波形/VAD 找候选边界，再逐句回听修正到第一个有效音节与最后一个有效音节。VAD 只能辅助，不能替代听感。
2. 字幕不要早于说话明显出现，也不要在下一句已经开始时仍停留上一句。说话快、连读或背景音明显的地方以实际听到的发音为准。
3. 对已指出的秒点和前后至少两句做局部回听；若发现整体滞后或提前，追查剪辑时间映射，而不是只平移单条字幕掩盖累积偏差。

## 5. 降噪与采访者声音处理

1. 先选受访者未说话的短区间估计环境噪声，再采用温和、分阶段降噪；优先提高可懂度，不以绝对静音为目标。不要把咬字、齿音、尾音和室内自然感一起抹掉。
2. 对独立出现的采访者短插话，优先剪掉对应音画片段；若必须保留画面节奏，可局部压低或静音并加短淡入淡出。若两人声音重叠，只能谨慎尝试声源分离或局部衰减，保留残留比损伤受访者更可取。
3. 降噪前后以相同音量对比试听受访者主声、停顿处和片头金句；检查抽吸、金属声、忽大忽小及采访者残留。不要宣称重叠人声已经完全去除。
4. 完成后统一受访者响度与峰值，避免不同章节开头音量突变；不让背景音乐盖过人声。

## 6. 去气口与音画同步

1. 只处理明显、冗长且不承担语义的吸气或等待；自然短呼吸可保留。不可截断前句尾音或后句首字，也不可把所有停顿压成机械连读。
2. 在波形上标记气口起止，给前后发音留余量，剪口加极短交叉淡化/淡入淡出，回听是否有点击声或音色跳变。
3. 优先对对应音画一起做等长剪切，并更新源到成片时间映射；禁止只剪短音频后用单帧冻结画面补时长。必要时使用真实连续的替代机位或 B-roll，不伪造口型同步。
4. 每次切点变化后，按新的成片时间线重算后续字幕。去气口完成之前不得把旧 SRT 烧录成最终版。

## 7. 导出与验收

1. 先导出无烧录字幕的当前音画母版，确认完整时长与连续帧；再从同一最终时间线生成 SRT/字幕图层并渲染。保留可追溯的源映射和修改记录。
2. 按顺序回听全片，同时检查每条字幕是否对应当前人声、是否有漏字或不合理孤词、字幕是否溢出/意外换行、人物卡与字幕是否互相遮挡。
3. 重点逐点检查所有降噪、采访者插话和去气口切点，以及用户指出的秒点；至少检查切点前后数秒、各章节衔接和视频末段。确认无定格单帧、黑帧、画面倒退、音频突变或字幕累积漂移。
4. 用 FFprobe 检查尺寸、帧率、时长与音轨，完整解码检查坏帧；但技术检查不能替代看画面和听原声。
5. 正式交付只保留当期最终版与需要的字幕/时间线；旧预览、临时降噪音轨和失败渲染放工作区，不混入交付目录。

## 返工边界

- 只改字幕文字或断句：重排受影响 cue，并检查前后相邻两句；不无故重做音频。
- 只改降噪强度且不改变时长：保留时间映射，仍回听人声起止与音量。
- 任何剪切、去气口、替换音画或变速：重算受影响及后续字幕时间，并检查画面连续性；不能把旧版字幕直接复用。
- 用户确认的字号、位置、人物卡和顶部观点保持不变，除非修改本身导致安全区冲突。
