# 预览与验收

## 两层预览

- 完整片头和第一个Q&A：原声节奏、人物/标题/气泡顺序、Q放大、顶部观点与底部字幕关系。
- 跨章节关键帧：最长标题、最长字幕、各机位、每类证据、数字和结尾。

短片检查全段，不强制拉长到60秒。最终完整回听，不以抽帧代替声音验收。

## 自动检查

1. node scripts/test.mjs：维护或修改skill脚本后运行，验证配置与时间线不变量。
2. node scripts/build.mjs --validate config.json：媒体、字幕边界和时长。
3. 生成项目npm run check：运行时、布局、动画与对比度；错误必须修复，警告明确核查。
4. FFprobe检查尺寸、帧率、时长、音轨；FFmpeg完整解码检查坏帧和文件损坏。

## 人工检查

- 论点对应原声与证据；没有断章取义或凭空添加效果。
- 原声切口不截字，语气自然，正文不是金句速度；音乐不盖人声。
- 按 [subtitle-audio-workflow.md](subtitle-audio-workflow.md) 回听每句字幕的起止点；去气口或采访者插话后的所有字幕重新对时，不能出现人声已开始、字幕仍停在上一句。
- 检查静音处残留背景杂音、采访者“嗯/是的”等非必要插话、过度降噪的金属声、剪气口后的音频跳变；人声重叠处不承诺完全分离。
- 跳看所有音画切点与末段，画面不得定格在单帧、黑帧或因音频剪短而补帧；字幕不得孤字、短词单独成帧、两行溢出或与口型明显错位。
- 顶部是提炼观点，下方是原话字幕；二者不重复承担职责。
- 金句小字与“断货”标签同级；全部机位避脸、避嘴、避底部控件区。
- 人物形象与身份属于当前项目；描边沿真实外缘，手臂遮挡正确。
- 主题两行、人物卡、三个气泡构图不挤；浅渐变卡上深灰字可读。
- 全片只有一套品牌渐变，CSS文字与SVG边框一致，无装饰小英文和未经要求的音效。
- 人物卡与人物同步1.5秒，主题逐字1.5秒，气泡各1秒，紧接放大1秒；项目覆盖另计。
- Q完整可读，逐行出现，长问题有足够停留；一个大模块不重复插Q。
- 证据插入保持同一回答原声连续，不把解释图冒充实际结果。
- 正式输出不含示例文字、测试标记、工作路径提示或缺失资产。

## 交付

只交付用户要求的范围和画幅：成片、当前执行脚本、字幕/时间线、原声剪辑资料、设计配置、质检报告与干净工程。保留来源追溯供内部使用；外发包剔除敏感路径和未获准素材。旧版、缓存、依赖目录、测试媒体留在work/archive，不混入正式包。
