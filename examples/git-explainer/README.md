# Git 是什么：知识讲解动画案例

[观看最终成片](git-explainer-final.mp4)｜横版 1920×1080｜约 3 分 15 秒｜中文人工旁白、烧录字幕与背景音乐。

这支片子从 Vibe Coding 的实际问题出发：AI 改完网站，怎么知道哪里变了、出了问题还能不能回去？随后用可见的画面动作讲清保存记录、试验分支和多人同时修改时的选择。卡通人物不是装饰，而是提出问题、操作、检查和协作的角色；物件状态与镜头承接旁白推进，不用整屏文字卡片代替演示。

它是 [`knowledge-explainer-video`](../../skills/knowledge-explainer-video/SKILL.md) 的完成案例，不是可直接替换文案的模板。仓库仅收录最终成片；原始录音、工程缓存、试片和中间版本不随案例公开。
