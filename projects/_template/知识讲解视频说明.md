# 知识讲解视频项目：{{日期-主题}}

> 使用 `$knowledge-explainer-video` 时复制并填写。项目事实、审批和时间线以 `project-manifest.json` 为唯一来源。

## 最低输入

| 项 | 内容 |
|---|---|
| 主题 | |
| 资料位置 | 文件、目录、链接或仓库 |
| 目标受众 | 可留空，由 Skill 推断并在第一次确认时锁定 |
| 输出目录 | `deliverables/` |

## 两次确认

- [ ] 内容确认：叙事结构、唯一讲稿、预计时长、视觉方向、卡通人物、真实视频策略和画幅
- [ ] 视觉确认：人物设定、三张代表帧、真实素材候选、素材占比和 8–12 秒连续转场样片

## 状态留痕

- [ ] `evidence_ready`：资料已建立证据索引，关键说法能回到原文
- [ ] `content_approved`：第一次确认已记录
- [ ] `visual_direction_approved`：第二次确认已记录
- [ ] `voice_recorded`：人工旁白已录制并锁定
- [ ] `timeline_locked`：画面、字幕与旁白已对齐
- [ ] `preview_approved`：完整预览已确认
- [ ] `qa_passed`：技术、内容、节奏、连续转场与授权检查通过
- [ ] `delivered`：正式成片、工程、清单和报告已归档

## 默认标准

- 主版：横版 1920×1080、30fps，时长按内容自适应，通常 90–180 秒。
- 节奏：主场景 8–15 秒；每 3–6 秒一次有意义的画面变化；给讲解、断句和重点停留留足空间。
- 视觉：画面化内容不少于 75%，纯文字时间不高于 15%；卡通人物使用 6–10 个透明背景姿势/表情贴图。
- 转场：从上一镜已有载体自然展开或收回，持续 0.8–1.5 秒，并检查边界前一帧、边界帧、后一帧。
- 声音：真人录音优先；未锁定人工旁白时只允许输出无声预览。
- 外部素材：必须记录来源、作者、授权、下载日期、哈希与使用区间；授权不清晰就不用。
